#Тестирование BooksCollector
#Для запуска тестов я использовал py -m pytest (с другими командами у меня возникает ошибка)
#Покрытие функционала

#В проекте реализованы автотесты закрывающие требования проекта

#add_new_book - проверка валидации длины (граничные значения 40/41 символ), проверка на дубликаты, базовый сценарий
#set_book_genre - проверка установки жанра и корректности сохранения
#get_book_genre - проверка получения жанра по имени книги
#get_books_with_specific_genre - проверка поиска книг по конкретному жанру
#get_books_genre - используется во всех тестах как источник истины для проверки количества и состава коллекции
#get_books_for_children - проверка бизнес-правила: исключение жанров с возрастным рейтингом («Ужасы», «Детективы»)
#add_book_in_favorites - проверка добавления в избранное и защита от дубликатов в списке избранного
#delete_book_from_favorites - проверка удаления из избранного и обработка случая несуществующей книги
#get_list_of_favorites_books - проверка получения актуального списка избранного

#Параметризация @pytest.mark.parametrize использована для тестов валидации длины, обработки дубликатов и проверки фильтрации книг для детей
